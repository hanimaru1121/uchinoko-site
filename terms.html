利用規約（うちの子ライブ「うちの子のデータ」受注制作）

改定のお知らせ（2026年10月7日）: 第1条2項（iPhone 版での受け取りに対応・iPhone 版が配信されなくなったときの扱い）と第16条（お客様の得になるだけの変更の扱い）を改定します。施行日は2026年10月22日です。施行日より前のご注文でも、iPhone 版で受け取れます。

この規約は、伊藤拓也（以下「運営者」）が提供する、うちの子ライブ「うちの子のデータ」の受注制作（以下「本サービス」）の条件を定めるものです。お申し込みの前にお読みください。

第1条 本サービスの内容

  1. 本サービスでは、お客様からお預かりしたペットの写真をもとに、写真風の絵と、約20本の短い動画のひとそろい（以下「うちの子のデータ」）を作り、お客様のアカウントに届けます。
  2. うちの子のデータは、うちの子ライブの iPhone 版・Mac 版の中で見ていただくものです。パソコンのブラウザ（Google Chrome）でも見られます。動作環境は特定商取引法に基づく表記のとおりです。iPhone 版は App Store（日本・米国）で配信しています。App Store での配信は Apple が決めるため、iPhone 版が配信されなくなったときも、Mac 版とブラウザで見られるようにし、ご希望により、うちの子のデータの動画を、ご自身の端末に保存できる形（動画ファイル）でお渡しします。この場合の使ってよい範囲も第10条と同じです。データとしてのお渡し（動画ファイルの送付など）は、この場合と第14条の場合を除き行いません。
  3. うちの子のデータ（絵と動画）は、AI（第5条）で作り、運営者が人の目で確かめて仕上げます。手で描いた絵や、撮影した映像ではありません。
  4. うちの子のデータには、うちの子ライブの中での動き（なでる・おやつなどへの反応）のための設定が含まれます。動きの仕組みはすべての子に共通で、お客様の子に合わせて新しい機能を作るものではありません。

第2条 規約への同意

  1. お客様は、この規約と、プライバシーポリシー（外国にある第三者への提供についての説明を含みます）に同意したうえで、お申し込みください。お支払いの画面で同意のチェックを入れたときに、同意したものとします。
  2. 未成年の方は、親権者など法定代理人の同意を得てからお申し込みください。

第3条 お申し込みの流れと契約の成立

  1. お客様は、運営者の窓口（note のお問い合わせ機能か、末尾の連絡用メールアドレス）からご相談のうえ、ペットの写真を3〜5枚お送りください。
  2. 運営者は写真を拝見し、作れるかどうかをお返事します。この確認に費用はかかりません。作るのが難しいと判断したときは、お申し込みの前にお断りします。
  3. 作れる場合、運営者はご注文内容の確認と、お支払いのページをメールでお送りします。
  4. お客様がお支払いのページで支払いを終えたときに、本サービスの契約が成立します。

第4条 料金とお支払い、承諾の通知

  1. 料金は、特定商取引法に基づく表記に書いたとおりです（24,800円。お支払いの総額です）。
  2. お支払いは前払いで、決済サービス Stripe を通じてクレジットカード等で行います。カードの番号は Stripe が直接受け取り、運営者は見ません。
  3. 運営者は、入金を確かめたら、お申し込みを受けたこと・受け取った金額・お届けの時期を電子メールでお知らせします。お客様は、この通知を電子メールで受け取ることに承諾するものとします。

第5条 AI と外部サービスの利用

  1. 運営者は、うちの子のデータを作るために、次の生成サービスを使い、お預かりした写真とそこから作った絵を送ります。
  2. 画像の生成: OpenAI（米国）
  3. 動画の生成: Replicate（米国）を通じて ByteDance グループの動画生成モデル（Seedance）
  4. 運営者は、これらのサービスで、お客様の写真が AI の学習に使われない設定を選びます。ただし、各サービスの中での取り扱いは、それぞれの規約とプライバシーポリシーに従います。
  5. AI で作るため、同じ写真からでも結果は毎回少しずつ変わります。運営者は、似るまで選び直し・作り直しをしてお届けしますが、写真に写っていない部分（反対側の模様・写真にない姿勢など）は、推測して作ることになります。
  6. 生成サービスの都合（停止・規約の変更・料金の変更）で制作が続けられなくなったときは、第11条のとおり返金します。

第6条 お預かりする写真

  1. お客様は、お送りいただく写真について、次のことを約束するものとします。
  2. お客様ご自身が撮った写真か、撮った人から制作に使ってよいと許しを得た写真であること（プロのカメラマンが撮った写真、ほかの人の SNS から保存した写真などは、撮った人の許しが要ります）
  3. 写っているペットが、お客様が飼っている（飼っていた）子か、飼い主の許しを得た子であること
  4. 写真にお客様以外の人が写っている場合、運営者はペットの部分だけを使い、人の姿はうちの子のデータに入れません。できるだけ人が写っていない写真をお送りください。
  5. 運営者は、お預かりした写真を本サービスの制作・作り直し・お問い合わせへの対応のためだけに使います。運営者のほかの作品や広告、AI の学習には使いません。
  6. 写真を作例として公開することはありません（作例に使えるのは、第9条で同意いただいたうちの子のデータ（絵と動画）だけです）。
  7. 写真の保存期間と削除は、プライバシーポリシーのとおりです。
  8. 第1項に反する写真であることがわかったときは、運営者は制作をお断りし、制作に入る前であれば全額を返金します。

第7条 お届け

  1. 運営者は、お支払いの確認と写真がそろった日から14日以内に、うちの子のデータをお客様のアカウントに届けます。遅れるときは、その前にご連絡します。
  2. 30日を過ぎても届けられないときは、お客様はご注文を取りやめ、全額の返金を受けることができます。
  3. 受け取りには、Sign in with Apple でのログインが必要です。うちの子のデータは、お客様がお支払いのあとにログインしたアカウントに届けます。

第8条 似ているかの確かめ、作り直しと返金

  1. 似ているかどうかを最終的に決めるのは、お客様です。
  2. 届いたうちの子のデータのうち「その子らしくない」と感じる絵・動画があれば、届いてから14日以内にお知らせください。2回まで無料で作り直します。1回の作り直しで、お知らせいただいた絵・動画をまとめて直します。
  3. 作り直しを経ても「うちの子だ」と思えないときは、届いてから30日以内にお申し出いただければ、全額を返金します。作り直しを待たずに返金を選ぶこともできます。理由を詳しく説明していただく必要はありません。
  4. 返金したときは、うちの子のデータをお客様のアカウントから取り下げます。端末に保存されたうちの子のデータも、次にアプリを開いたときに消えます。
  5. 作り直しの回数や期間を過ぎた後のご相談にも、できる範囲で応じます。

第9条 作例としての公開（別途の同意）

  1. 運営者は、お客様の同意がない限り、うちの子のデータも写真も公開しません。
  2. 運営者は、お届けの後に、作例として使ってよいかを別途おたずねすることがあります。お客様は次から選べます。選ばなくても、料金や作り直し・返金の条件は変わりません。
  3. (a) 公開しない
  4. (b) 名前を出さずに、うちの子のデータ（絵と動画）を作例として使ってよい
  5. (c) うちの子のデータ（絵と動画）に加えて、ペットの名前（呼び名）と感想も載せてよい
  6. 同意した後でも、いつでも取り消せます。取り消しのご連絡を受けたら、運営者が管理する場所（ウェブサイト・SNS など）からすみやかに外します。すでに第三者が保存・共有したものは、運営者には消せないことがあります。

第10条 うちの子のデータの権利と、使ってよい範囲

  1. うちの子のデータ（絵と動画）、うちの子ライブのプログラム・デザインについて、運営者が持つ権利は運営者に残ります。生成サービスの規約によって運営者が受け取った出力の権利も同じです。
  2. 運営者は、お客様（ご家族を含みます）に、うちの子のデータを次の範囲で使うことを、期間の定めなく許します。
  3. うちの子ライブの中で見ること
  4. 画面の録画・スクリーンショットを、ご自身の SNS への投稿や、家族・知人に見せるなど、お金を受け取らない形で共有すること
  5. 次の使い方は、事前に運営者の同意を得てください。
  6. うちの子のデータの絵・動画を使ったグッズ・印刷物・動画などを売ること、広告に使うこと
  7. うちの子のデータのファイルを取り出して配布すること、ほかのアプリ・サービスに取り込むこと
  8. うちの子のデータを、実在の人物や他人のペットになりすますなど、人をだます目的に使うことはできません。生成サービスの規約により、AI で作ったものを人が撮影・制作したものと偽ることもできません。

第11条 キャンセルと返金

  1. お支払いの前は、いつでも取りやめられます。
  2. お支払いの後、制作に入る前のキャンセルは、全額を返金します。制作に入ったときは、メールでお知らせします。
  3. 制作に入った後のキャンセルも、全額を返金します。
  4. 運営者の都合（病気・生成サービスの停止など）で制作を続けられないときは、全額を返金します。
  5. 返金は、お支払いに使ったカードへ、お申し出の確認から7日以内に手続きします。決済の手数料はお客様にご負担いただきません。

第12条 禁止事項

お客様は、次のことをしないでください。 1. 第6条第1項に反する写真を送ること 2. うちの子のデータやうちの子ライブを、第10条で許した範囲を超えて使うこと 3. うちの子ライブのプログラム・サーバーに、不正にアクセスすること、負荷をかけること、解析してうちの子のデータを取り出すこと 4. ほかの人のアカウントでログインすること、アカウントを他人に譲ること 5. 運営者やほかの人をおとしめること、困らせること

第13条 アカウントの削除

  1. お客様は、うちの子ライブの中からいつでもアカウントを削除できます。
  2. アカウントを削除すると、そのアカウントに届けたうちの子のデータは取り下げられ、端末からも消えます。同じうちの子のデータをあとから受け取り直すことはできません。削除の前に、画面で確認をお願いします。
  3. アカウントの削除による返金はありません。ただし、第8条・第11条の返金の期間中であれば、削除の前にご相談ください。
  4. アカウントの削除でサーバーから消えるもの・残るもの（支払いの記録など）は、プライバシーポリシーのとおりです。

第14条 本サービスの終了

  1. 運営者は、本サービスやうちの子ライブの提供を終えるときは、終える日の90日前までに、ウェブサイトとお客様の連絡先へのメールでお知らせします。
  2. 終了のお知らせから終了の日までの間、お客様のご希望により、うちの子のデータの動画を、ご自身の端末に保存できる形（動画ファイル）でお渡しします。この場合の使ってよい範囲も第10条と同じです。
  3. 端末に保存されたうちの子のデータがサービスの終了後も見られるかは、端末の OS の更新などに左右されるため、お約束できません。
  4. 終了の日に、届ける前・作り直しの期間中のご注文があれば、全額を返金します。
